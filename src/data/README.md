# data

Datos y configuración: valores de ajuste (`gameTuning.ts`) y datos de los niveles (`levels/`).

`levels/level1.json` es una copia literal del mapa aprobado (`docs/02_diseno/MAPA_NIVEL_1_APROBADO.txt`)
más las tablas de coordenadas de `CONTEXTO_MAESTRO.md`. Una prueba (`tests/world/level1Data.test.ts`)
falla si la copia y los documentos dejan de coincidir. No se edita sin aprobación humana.
