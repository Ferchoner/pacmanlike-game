# PAC-BIG-MAN --- Paquete inicial v1.0

Paquete autónomo para Claude, ChatGPT u otra IA.

## Inicio

1.  Entrega la carpeta completa o ZIP a la IA.
2.  Pide que siga `06_prompts_IA/PROMPT_MAESTRO.md`.
3.  La IA debe resumir el alcance y auditar el mapa antes de escribir
    código.
4.  Revisa y aprueba el plan.
5.  Avanza con `PROMPTS_POR_FASE.md`.
6.  Actualiza matriz y manifest al recibir recursos.
