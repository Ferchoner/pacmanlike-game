# Checklist de recepción

-   [ ] ID asignado en matriz.
-   [ ] Original preservado.
-   [ ] Autor/proveedor y URL registrados.
-   [ ] Licencia revisada y compatible con distribución prevista.
-   [ ] Dimensiones/formato verificados.
-   [ ] Ficha técnica completada.
-   [ ] Spritesheet probado o audio reproducido.
-   [ ] Ruta añadida al manifest.
-   [ ] Estado actualizado en el manifest y, a mano, en la matriz (.csv y .xlsx).
-   [ ] Aprobación final registrada. Sugerencia: conservar originales en
    `assets/source/` y recursos preparados para carga en
    `public/assets/`. No sobrescribir originales.
